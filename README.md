The goal of this project was to break down key performance parameters of AstroSage astrologers and present them in a simple, interactive, and insight-driven format. From call behaviour to customer ratings, the dashboard brings multiple data points together for quick decision-making.
Dashboard Highlights:
- Fully interactive dashboard with filters & slicers.
- Multiple charts to track performance indicators and trends.
- KPIs reflecting average call duration, total calls, customer ratings & more.
- Well-structured layout to make the analysis intuitive and easy to navigate.
- Insights designed to help identify improvement areas in customer experience.
Tech & Skills Used:
 • Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)
 • Data Cleaning, Formatting & Transformation
 • Dashboard Visualization & Layout Techniques
